# 高校账号删除与请假监管员切换辅导员

- 提出日期：2026-11-27
- 当前状态：`done`
- 需求类型：高校账号管理

平台运维可删除高校管理员和请假监管员账号。请假监管员可在新增或编辑时关联本校教师工号，登录后可在监管页面与辅导员工作台之间切换。

删除通过 `DELETE /uni/admin/delete` 完成，移除成员关系和角色关联并软删除用户。两类高校账号共用已有教师关联，辅导员工作台只处理关联教师负责的学生。上线需应用迁移 `000031_university_account_management` 后重新加载权限。

删除后可重新添加同名高校账号，历史软删除记录由同一事务释放用户名，新账号获得独立用户 ID 和会话。活跃账号的用户名仍保持全局唯一。

平台运维编辑账号时可在高校管理员和请假监管员之间切换。角色、成员关系和会话截止时间在同一事务中更新，原辅导员关联可继续使用。
